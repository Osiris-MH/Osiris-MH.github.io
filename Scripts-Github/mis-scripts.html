OsiReverse-shell.php

Descripción: Una reverse shell escrita en PHP diseñada para ser utilizada en entornos de pruebas de penetración. Este script establece una conexión con un servidor remoto (IP y puerto configurables) y ejecuta un shell interactivo.

Características Principales:

  • Conexión Remota: Establece una conexión con un servidor remoto mediante PHP, proporcionando acceso al sistema comprometido a través de un shell interactivo.
  • Auto-discovery del entorno: Detecta información del sistema como el usuario, UID, GID, versión de OS y la shell en uso.
  • Uso de stream_select: Permite una comunicación eficiente y sin bloqueos entre el servidor remoto y el shell.

OsiReverse-shell-persistent.php

Descripción: Una reverse shell avanzada escrita en PHP diseñada para ser utilizada en entornos de pruebas de penetración. Este script establece una conexión con un servidor remoto (IP y puerto configurables) y ejecuta un shell interactivo. Además, incluye características de persistencia, lo que permite que el script se ejecute automáticamente tras un reinicio del sistema. Utiliza stream_select para manejar la comunicación, lo que lo hace eficiente y resistente a los bloqueos.

Características Principales:

  • Persistencia: Copia el script a /tmp/.ld.php y lo agrega a .bashrc para asegurar que se ejecute automáticamente tras cada reinicio.
  • Auto-discovery del entorno: Detecta información del sistema como el usuario, UID, GID, versión de OS y la shell en uso.
  • Uso de stream_select: Permite una comunicación eficiente y sin bloqueos entre el servidor remoto y el shell.
  • Daemonización: Puede correr en segundo plano como un demonio, útil para operaciones encubiertas.
  • Compatibilidad: Compatible con sistemas que ejecuten PHP y proporcionen un entorno adecuado.

DirHound 🐕‍🦺

Descripción: Es una herramienta de enumeración de directorios y archivos oculta diseñada para pruebas de penetración y auditorías de seguridad web. Construida para ser rápida, eficiente y flexible, DirHound permite descubrir recursos ocultos en servidores web utilizando ataques basados en diccionarios, soporte multihilo y opciones avanzadas de filtrado por códigos de respuesta.

Características Principales:

  • 🚀 Escaneo multihilo para una búsqueda rápida y eficiente.
  • 🎯 Filtros avanzados por códigos HTTP (200, 301, 403, etc.).
  • 📂 Soporte para wordlists personalizadas.
  • 🛡️ Manejo robusto de errores y desconexiones.
  • 🔥 Opcional: integración con proxies para anonimato.

Ideal para pentesters, bug hunters y profesionales de ciberseguridad que buscan una solución ligera pero potente para la enumeración web.
