🌐 Enumeración Web

Al acceder al puerto 80, se carga la página por defecto de Apache en Ubuntu. Esto confirma que el servidor HTTP está activo, pero aún no ha sido personalizado. No hay contenido útil a simple vista, lo que sugiere que debemos buscar rutas ocultas o archivos fuera del índice principal.

Gobuster revela múltiples directorios interesantes como /private/, /dev/, y /staging/, todos accesibles con redirección 301. También aparecen archivos sensibles como .htaccess y .htpasswd, aunque protegidos (403). Hay material para explorar más allá del índice visible.

Al acceder al directorio /images/, se muestra un listado de archivos con nombres cargados de historia: Duarte.jpg, Mella.jpg, Sanchez.jpg, y Altar_de_la_patria.jpeg. Esto sugiere que las pistas podrían estar ocultas en las imágenes.

El directorio /staging/ expone varios archivos .txt y dos subdirectorios: 1844/ y zone7/. La presencia de múltiples archivos sugiere que este espacio se usa para pruebas o desarrollo. El nombre 1844 podría tener carga histórica, así que vale la pena inspeccionarlo primero. Este hallazgo abre la puerta a posibles pistas narrativas o credenciales ocultas.

Dentro de /staging/1844/secrets.txt encontramos una secuencia en hexadecimal.

Al decodificarla con CyberChef, obtenemos el mensaje: “Will you be able to find the secret file?” Esto confirma que estamos en una fase de pistas encadenadas. El reto ahora es identificar qué archivo o ruta oculta contiene la siguiente clave

En /staging/file.txt encontramos una cadena larga que parece un hash o un relleno intencional.

El archivo contiene una cadena codificada en Base64. Al decodificarla con CyberChef, obtenemos el mensaje: “Not everything can be seen with Binwalk and ExifTool.” Esto sugiere que las herramientas tradicionales de análisis de archivos pueden no revelar todas las pistas. Es una advertencia narrativa: el reto exige pensar más allá de lo obvio.
